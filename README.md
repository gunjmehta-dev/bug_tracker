# 🐞 BugTracker Pro

A sleek, modern, and fully functional **frontend-only bug tracking system** to manage and resolve bugs with style.

## 🛠️ Features

- 📋 Add new bugs with a single click
- ✅ Mark bugs as resolved or reopen them
- 🗑️ Delete bugs
- 🔍 Filter by:
  - All
  - Resolved
  - Unresolved
- ⚡ Fast, clean, responsive UI
- 💻 Pure HTML, CSS, and JavaScript (no frameworks)
